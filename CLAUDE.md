## API Reference

Do not refer to the `docs/typedoc/html` documentation unless
investigating something specific to the html output. Always
start with `docs/typedoc/markdown/globals.md` which will present
links to more specific documentation in markdown.

If `docs/typedoc` does not exist, run `npm run docs` to generate
it.

## Character formatting

Use '-' instead of — (em dash) in source code. More generally,
prefer expressing with characters typically available for a
standard US keyboard layout. For example, instead of ➜, use '->'
as an arrow.
